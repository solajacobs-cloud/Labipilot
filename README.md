# LabiPilot

LabiPilot is a custom AI engineering learning website inspired by the structure of Framis, but with original branding, content, layout, and visuals.

## Included

1. Public landing page
2. Learning method section
3. Interactive learning tracks
4. Project labs
5. Outcomes section
6. Highlights section
7. Pricing preview
8. Waitlist form
9. SEO metadata, robots file, sitemap, and social preview image

## Deploying to Vercel

1. Push these files to GitHub.
2. Import the repository into Vercel.
3. Keep the default static site settings.
4. Deploy.

No environment variables are required for this first version.
