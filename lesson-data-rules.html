Lesson 04

Plan data before connecting a database.

Useful apps need clear records, simple forms, and sensible rules. This lesson turns a product idea into a database plan that is easy to build and verify.

Goal

Learners should be able to describe what data the app saves, who can read it, who can change it, and how the interface confirms that the action worked.

Data planning checklist

  1. Name the record the app saves, such as waitlist signup, lesson progress, project note, or support request.
  2. List the fields for that record and mark which fields are required.
  3. Decide what the user sees after saving the form.
  4. Define who can read each record and who can update it.
  5. Write one verification step that proves the saved record exists.

Database brief prompt

Use this prompt before adding Supabase or any other database. It keeps the first schema small and testable.
