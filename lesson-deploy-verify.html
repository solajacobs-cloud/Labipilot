Lesson 05

Ship the app, then test the live link.

A deployment is only finished when the live URL loads, key links work, forms behave as expected, and the build logs have been checked.

Goal

Learners should be able to push a change, confirm Vercel built the right commit, and run a short production checklist before sharing the app.

Launch checklist

  1. Push the final change to the connected GitHub repository.
  2. Open Vercel and confirm the latest production deployment is ready.
  3. Check the deployment commit message matches the change you expected.
  4. Open the live URL and test the homepage, dashboard, lessons, forms, and footer links.
  5. Record any failed route, console error, or unclear copy as a focused fix.
