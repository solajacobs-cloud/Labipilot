Lesson 02

Create the first usable interface.

Turn the build brief into a clear first screen with visible sections, useful copy, working links, and a layout that survives mobile checks.

Goal

Your first interface should make the product understandable within a few seconds. Do not start with decoration. Start with the user task, the key action, and the proof that the page works.

Interface checklist

  1. Name the product and the main user outcome in the first viewport.
  2. Add navigation links for the pages the user expects.
  3. Use real section titles instead of placeholder copy.
  4. Make the primary action obvious and testable.
  5. Check the page at phone width before moving on.

Build prompt

Ask your AI tool for a complete first screen, then inspect whether the result matches the brief.

Using this app brief, create the first usable interface.
Prioritise:
1. clear headline and value
2. navigation links
3. primary action
4. three supporting sections
5. responsive mobile layout
6. no placeholder copy
Return the HTML, CSS, and any JavaScript needed.
