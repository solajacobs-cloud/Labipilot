Privacy

How LabiPilot handles basic site data.

This first version uses browser storage for preview features. A production database should be connected before collecting live learner data.

What this preview stores

The waitlist and lesson progress demos currently save entries in the visitor's own browser using local storage. This lets the preview work without accounts or a backend.

Production data

When LabiPilot starts collecting real signups, it should use a dedicated database, clear access rules, and only the information needed to respond to learners.

Contact

Use the contact page for privacy questions, removal requests, or corrections once live data collection is enabled.

Updates

This notice should be reviewed before adding payments, login, analytics, email marketing, or third party integrations.
